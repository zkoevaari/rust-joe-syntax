Rust syntax for `joe` and `ne`
==============================

This is an effort to provide an up-to-date and improved Rust language syntax definition file for *Joe's Own Editor*.\
The file can also be used for the *nice editor*, as it happens to use the same syntax definition system.

Due to the conflicting licenses, this is a complete rewrite, although one that aims to consider in particular all the issues that came up in recent years (and were fixed) in the version bundled with `joe`. So we hope this provides an experience that is at least as good as the old one, with many new features.
